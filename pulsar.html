LilyGO T-Display-S3 · Portfolio Dashboard

Pulsar

A portfolio dashboard for the LilyGO T-Display-S3. It tracks your own positions with live public quotes, converts everything into one currency with ECB reference rates, and keeps a daily record of what the portfolio did. It also has a view for money borrowed to invest, an allocation view that shows drift against your targets, and a small web app at pulsar.local to edit it all.

Features

What Pulsar does

Five screens, two buttons

Positions in a grid, a full-screen detail view, the portfolio total, a loan view and an allocation view. A long press of BOOT moves between views; USER steps within the current one.

Live public quotes

One HTTPS request per position per loop pass, so the clock, buttons and web server never freeze. Polling follows each venue's real trading session, and a failed request keeps the last good price, dimmed.

Numbers it will not fake

A one-day move past 25% is flagged as a probable split, and quotes more than 36 hours apart are flagged as coming from different sessions. Everything is converted with ECB rates, and the return figure is explained, not hidden.

Loan-funded investing

For money borrowed to invest: what has been drawn, what it has cost in interest and what it bought is worth. The headline is net equity, with a money-weighted return set against the borrowing rate.

Allocation and drift

Each targeted fund as a bar against its target, with drift measured within the targeted sleeve and the amount that would close the worst gap.

Web app, OTA and alerts

Edit positions at pulsar.local (stored in NVS flash), flash new firmware over Wi-Fi into a verified second slot, and optionally post Slack-style webhook alerts that never contain a price or an amount.

Hardware

Bill of materials

ComponentNotes
LilyGO T-Display-S3ESP32-S3 with a built-in 320×170 ST7789 display, two buttons (BOOT and USER) and USB-C; all-in-one, no extra parts
USB-C cableFor the first flash and for power; later updates can go over Wi-Fi
Wi-Fi networkNeeded for quotes, exchange rates and the clock; credentials go in include/secrets.h

No soldering and no external modules. There is no broker integration either: you own the position data, the device fetches only public prices, and no credentials for any brokerage exist anywhere in the project.

Build & Flash

Get it running

# clone
git clone https://github.com/mabushi-lab/Pulsar
cd Pulsar
 
# add your Wi-Fi credentials (and an OTA password)
cp include/secrets.h.example include/secrets.h
 
# first upload: hold BOOT, press RST, release BOOT
pio run -t upload
pio device monitor
 
# later updates go over Wi-Fi
PULSAR_OTA_PASSWORD=yourpassword pio run -e ota -t upload

PlatformIO downloads LovyanGFX and ArduinoJson automatically; the board target is lilygo-t-displays3. After flashing, open http://pulsar.local/ to enter your positions.
